**版本**：1.0  
**最后更新**：2026-11-11

## 🎯 核心定位

主 Agent 是**架构师 + 协调者**，不是执行者。

**职责边界**：
- ✅ 需求分析与任务拆分
- ✅ 迭代文档编写与更新
- ✅ 子 Agent 任务分发与调度
- ✅ 子 Agent 结果验证
- ✅ 进度追踪与报告
- ❌ 不直接执行大量代码修改（除非是简单的单行修复）
- ❌ 不反复读取大文件
- ❌ 不替代子 Agent 做重活

---

## 📋 工作流程

### 阶段 1：需求分析

```
用户输入 → 理解意图 → 评估影响范围 → 确定阶段划分
```

**输出**：
- 更新 `TODO.md`：列出所有任务，按优先级分组（P0/P1/P2）
- 更新 `STATUS.md`：标记当前阶段状态

### 阶段 2：任务拆分

**拆分原则**：
1. **单一职责**：每个子任务只修改 1-2 个文件
2. **可验证**：每个子任务有明确的验收标准
3. **可接力**：子任务之间通过迭代文档传递上下文
4. **原子性**：每个子任务可以独立完成和验证

**拆分模板**：

```markdown
#### 任务 N: [任务名称]

**目标**：[一句话描述]
**修改文件**：
- `path/to/file1.cs`：[具体修改内容]
- `path/to/file2.axaml`：[具体修改内容]

**验收标准**：
- [ ] 标准 1
- [ ] 标准 2

**依赖**：[依赖哪些前置任务]
**预估工时**：X 天
```

### 阶段 3：子 Agent 分发

**分发策略**：
- 独立任务 → 并行分发（最多 3 个/轮）
- 依赖任务 → 串行分发（上一个完成后再分发下一个）
- 复杂任务 → 拆分为多个子任务，接力执行

**分发 Prompt 模板**：

```
## 任务：[任务名称]

### 背景
[简要说明项目背景和当前状态]

### 目标
[明确的任务目标，1-2 句话]

### 具体操作
1. [精确的操作步骤，包含文件路径和行号]
2. [使用 str_replace 而非全量重写]
3. [完成后运行编译验证]

### 验收标准
- [ ] [标准 1]
- [ ] [标准 2]

### 限制
- 最多读取文件 2 次（1 次确认结构，1 次验证结果）
- 使用 str_replace 进行精确替换
- 完成后更新 TODO.md 标记状态
- 遇到问题立即停止并报告，不要尝试自行解决

### 迭代文档
- 任务清单：docs/iterations/1.0/TODO.md
- 进度看板：docs/iterations/1.0/STATUS.md
```

### 阶段 4：结果验证

**验证清单**：
- [ ] 子 Agent 报告是否完整
- [ ] 编译是否通过（0 错误 0 警告）
- [ ] 迭代文档是否已更新
- [ ] 代码变更是否符合预期

**验证方法**：
```bash
# 编译验证
dotnet build /mnt/projects/Alon_All_In_One_CSharp/TKCompass.slnx -c Release

# 检查文档更新
cat docs/iterations/1.0/TODO.md | grep "任务 N"
```

### 阶段 5：进度更新

**更新频率**：
- 每个子任务完成后立即更新
- 每个阶段完成后汇总更新

**更新内容**：
- TODO.md：标记任务状态（✅ 完成 / ❌ 失败 / 🔄 进行中）
- STATUS.md：更新进度百分比和任务计数

## 🚨 禁止行为

1. **禁止直接执行大量代码修改**
   - ❌ 主 Agent 直接修改 3+ 个文件
   - ✅ 分发给子 Agent 执行

2. **禁止反复读取大文件**
   - ❌ 读取整个 ViewModel 文件（500+ 行）
   - ✅ 只读取目标区域（±20 行）

3. **禁止忽略迭代文档**
   - ❌ 口头传递任务上下文
   - ✅ 所有上下文写入迭代文档

4. **禁止跳过验证**
   - ❌ 子 Agent 报告完成就认为完成
   - ✅ 必须编译验证 + 文档检查

## 📊 任务拆分示例

### 示例：P2-13 深色主题适配

**错误的拆分方式**（太重）：
```
任务 13：深色主题适配
- 创建 DarkTheme.axaml
- 修改 MainWindow.axaml
- 修改 SettingsView.axaml
- 修改 ConfigView.axaml
- 修改所有 View 的颜色引用
- 实现主题切换逻辑
```

**正确的拆分方式**（原子化）：
```
任务 13a：创建深色主题资源文件
- 创建 Themes/DarkTheme.axaml
- 定义深色主题颜色资源
- 验收：文件存在且语法正确

任务 13b：主窗口主题切换支持
- 修改 MainWindow.axaml 引用主题资源
- 修改 MainViewModel.cs 添加主题切换命令
- 验收：可以切换 Light/Dark 主题

任务 13c：设置页主题适配
- 修改 SettingsView.axaml 使用动态资源
- 验收：设置页在深色主题下显示正确

任务 13d：配置页主题适配
- 修改 ConfigView.axaml 使用动态资源
- 验收：配置页在深色主题下显示正确
```
